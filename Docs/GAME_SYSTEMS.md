# Игровые системы — Ыйман

## Подключение в главную сцену (Никита)

1. Добавить один GameObject `GameManager` с компонентом `GameManager`.
2. Добавить `CandleFlame` на корневой объект Player: Max Flame = 100, Loss Per Second = 1.
3. Добавить игровую сцену в File → Build Profiles → Scene List. Это нужно для перезапуска.
4. При открытии сцены игра находится в Ready и время остановлено. Кнопка «Играть» вызывает `GameManager.Instance.StartGame()`.
5. Для света читать `flame.Normalized` (0–1). При нуле выключать свет; предлагаемый радиус при положительном пламени — 1,2–5.

Общие сцены, управление игроком, свет, UI и префабы предметов этой задачей не изменяются. Они подключаются владельцами соответствующих частей.

## Интерфейс

| Вызов / свойство | Назначение |
| --- | --- |
| `GameManager.Instance.State` | `Ready`, `Playing`, `Won`, `Lost` |
| `GameManager.Instance.StateChanged` | Событие `Action<GameState>` для UI; после подписки сразу отобразить текущее State |
| `StartGame()` | Старт только из Ready |
| `Win()` / `Lose()` | Завершение только из Playing; повторные вызовы игнорируются |
| `Restart()` | Перезагрузка активной сцены, возврат в меню Ready; повторное нажатие в том же кадре игнорируется |
| `flame.Value` / `flame.MaxFlame` | Текущее / максимальное пламя |
| `flame.Normalized` | Значение для полоски и света, от 0 до 1 |
| `flame.Restore(25f)` | Воск: +25, максимум 100 |
| `flame.Hurt(20f)` / `flame.Hurt(35f)` | Ветер / тень |

Пламя убывает на 1 в секунду только во время Playing. В меню и после финала восстановление, урон и горение отключены. Нулевое пламя немедленно вызывает Lose. Отрицательные и некорректные значения урона/восстановления игнорируются.

Триггеры Никиты перед взаимодействием проверяют Playing. Воск уничтожается после одного сбора. Ветер и тень наносят урон один раз при входе. Алтарь вызывает Win только для игрока с `CandleFlame.Value > 0`. Для Collider2D на дочернем объекте использовать `GetComponentInParent<CandleFlame>()`.

## Проверка

В Unity: Window → General → Test Runner → PlayMode → Run All. Тесты игровых систем используют отдельную тестовую сцену, проверяют состояния, границы пламени, горение и перезапуск. После подключения также проверить полный игровой цикл в финальном билде.

Проверено: 10 из 10 PlayMode-тестов прошли в установленном Unity 6000.6.9f1 на исходниках main a092eba. Настройки версии Unity и пакетов не входят в изменения. Подключение к финальной Game.unity и проверка полного билда остаются этапом интеграции Никиты.
