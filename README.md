# Последняя свеча

Атмосферный 2D-платформер про гонку со временем. Пламя свечи — это и здоровье, и единственный источник света: чем слабее огонь, тем темнее вокруг. Пройди три подземелья, собирай воск, избегай сквозняков и теневых мотыльков — и донеси живой огонь до алтаря.

Проект создан на хакатоне командой из четырёх человек (Unity 6, 2D, URP).

## Как скачать и запустить игру

**Важно:** игра распространяется целой папкой, а не одним файлом `.exe`.

1. Скачай архив `LastCandle_Windows.zip` со **страницы игры на джеме** (Windows, ~47 МБ).
2. Распакуй архив **целиком** в любую папку (ПКМ → «Извлечь всё»). Не запускай exe прямо из архива.
3. Запусти `Candle.exe` из распакованной папки.

Рядом с `Candle.exe` обязательно должны лежать `UnityPlayer.dll` и папка `Candle_Data` — без них игра не запустится (ошибка «система не обнаружила UnityPlayer.dll» означает, что распакован только exe).

## Управление

| Клавиша | Действие |
|---|---|
| A / D или ← / → | движение |
| ПРОБЕЛ | прыжок (удерживай — выше) |
| ESC | пауза |

## Как играть

- Золотой воск возвращает 25% пламени.
- Сквозняки, теневые зоны и мотыльки отнимают пламя.
- Падение в пропасть гасит свечу мгновенно.
- Дошёл до алтаря с горящей свечой — переходишь на следующий уровень. Потух — тьма победила.
- После победы на третьем уровне кнопка возврата ведёт в начало игры.

## Структура проекта

```
Assets/_Game/
  Art/        — визуальные ассеты
  Audio/      — звуки
  Prefabs/    — префабы (уровни, воск, ветер, алтарь, мотылёк)
  Scenes/     — Game (уровень 1), Trials (уровень 2), LastPassage (уровень 3)
  Scripts/    — код (Core: GameManager; Gameplay: пламя, воск, враги, алтарь, UI)
```

## Сборка из исходников

1. Открой проект в **Unity 6000.6.x** (версия указана в `ProjectSettings/ProjectVersion.txt`).
2. Убедись, что в Build Profiles (File → Build Profiles → Windows → Scene List) включены сцены `Game`, `Trials`, `LastPassage` в этом порядке.
3. Нажми Build и выбери пустую папку вне `Assets/`.

Для запуска проекта в редакторе достаточно открыть сцену `Assets/_Game/Scenes/Game.unity` и нажать Play.
