# Уровень Абдулманапа — Level_01

## Что добавлено

- `Assets/_Game/Prefabs/Levels/Level_01.prefab`: отдельный редактируемый уровень.
- `Assets/_Game/Scenes/LevelSandbox.unity`: тестовая сцена с копией существующего игрока, камеры и света. Общая Game.unity не менялась.
- 24 платформы, 7 капель воска, 3 зоны ветра, 2 тени и алтарь. Игровые объекты — вложенные экземпляры командных префабов, поэтому будущая логика придёт из их исходников.
- Три участка: Entrance, Trial, AltarApproach. Начало игрока: (-4, -3.3). Алтарь: x=379.5. Платформы на слое Ground (3).
- Горизонтальные разрывы 2.5 единицы, перепады высоты не больше 0.8. Примерная нижняя оценка движения до алтаря при скорости 6: 64 секунды; целевые 60–120 секунд требуют плейтеста.

## Как открыть и проверить

1. Получить ветку feature/levels и открыть проект в Unity 6000.6.4f1.
2. Открыть Assets/_Game/Scenes/LevelSandbox.unity; дождаться импорта, проверить Console.
3. Нажать Play. Движение — A/D или стрелки, прыжок — Space. Для полного прыжка удерживать Space.
4. Пройти маршрут слева направо, проверить прыжки, заметность приземления при малом свете и время прохождения.
5. После падения остановить Play и запустить снова: обработчик падения пока отсутствует в main.
6. Менять уровень двойным кликом по Level_01.prefab (Prefab Mode). Не применять изменения игрока к общей сцене.

## Передача Никите

Добавить Level_01.prefab в Game.unity с Position=(0,0,0), Rotation=(0,0,0), Scale=(1,1,1). Удалить прежние тестовые платформы и дубли Wax/Wind/Shadow/Altar из общей сцены. Игрок, камера, GameManager и UI остаются вне префаба уровня. Поставить существующего игрока в (-4,-3.3,0). Проверить его groundLayer=Ground, groundCheck и ссылку target камеры.

- [ ] Импорт без ошибок, один игрок, камера и AudioListener.
- [ ] Полное прохождение за 60–120 секунд; каждое приземление достижимо и видно.
- [ ] При ошибке в прыжке корректное поражение и повтор.

- [ ] При малом запасе свет уменьшается, но путь читается.
- [ ] При нуле огня проигрыш, у алтаря с живой свечой победа.

Шаблон ошибки: версия/коммит → шаги → ожидалось → получилось → P0/P1/P2 → скриншот/видео.
